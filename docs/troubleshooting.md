# 常见问题

[← 返回 README](../README.md)

### 下载一直停在 0%

先看任务状态：「正在发现下载节点」表示还没找到其他用户，「已连接 N 个节点 · 等待可用分片」表示有连接但对方暂时没有可用的数据。旧资源可能已经没人做种，换一个字幕组或更新的资源通常就能解决。

- 内置下载器会让系统为每个连接选择网络路由，同时使用 IPv4 / IPv6，不需要修改 Windows 或代理设置。
- 种子没有 Tracker 时，会补充少量公共 Tracker（可在「偏好设置 → 资源与网络」关闭）；私有种子不受影响。
- 90 秒收不到数据会自动换用其他来源，可在「偏好设置 → 下载」调整或关闭。
- 点「恢复」会重新寻找节点。

### 下载的视频打不开或没有字幕

本软件不含播放器，视频交给系统默认播放器打开。番剧多为 HEVC / 10bit 编码并带 ASS 特效字幕，Windows 自带播放器通常无法正常显示。请安装 PotPlayer、mpv 或 MPC-HC，并设为 `.mkv` / `.mp4` 的默认打开方式。

### 启动时提示下载目录不存在

保存的下载目录被删除、改名或所在磁盘未连接时会出现。选择新目录即可；已有的文件不会被移动。

### 追更提醒没有出现

启动时会自动检查一次，之后可以在「我的追番」点「检查追更」再查。它只针对你下载过的番剧和字幕组，以下情况不会提醒：

- 该字幕组还没有发布新集，或资源站暂时没有返回结果；
- 已经下载到最后一集；
- 新集被「忽略」过；
- 在番剧详情页把「追更」设成了「不追更」；
- 设成「自动下载」的番剧不弹提示，新集会直接出现在「下载任务」中。

### 更换下载目录后，旧文件还在原处

更换目录时如果选了「留在原处」，已下载的番剧不会移动，但仍能在「我的追番」中播放。想移过去的话，把目录改回原来的位置再改一次，在提示中选「一起移动」。外部下载器的任务需要在对应软件里自行移动。

### 资源站或放送表一直加载失败

很多资源站和 Bangumi 在部分网络环境下需要代理。先确认代理软件已开启「系统代理」，或在「偏好设置 → 资源与网络 → 代理」手动填写代理地址和端口。连不上 Bangumi 时，「本季放送」会先显示上次成功加载的放送表。

### 关闭窗口后程序还在运行

选择了「最小化到托盘」后，程序会在后台继续下载和检查追更。在任务栏右下角的托盘图标上右键选「退出」即可完全退出；想改回每次询问，到「偏好设置 → 通用 → 窗口」修改「关闭窗口时」。

### 提示磁盘空间不足

开始下载前会按资源站给出的大小检查下载目录所在磁盘的剩余空间（另留出约 512 MB）。清理磁盘，或在「偏好设置 → 数据」把下载目录换到空间更大的磁盘即可。

### 海报不显示或占用空间较大

海报缓存在「偏好设置 → 数据」中可以查看大小并清理，清理后会在下次显示时重新下载。

### 想再看一次欢迎页

退出软件，把 `%USERPROFILE%\.miku-library\config.json` 中的 `disclaimer_accepted` 改为 `0`，再次启动即可。

### 打开第二个窗口没有反应

同一数据目录只允许运行一个实例。再次打开会切换到已经运行的窗口；如果它还在启动中，请稍等再试。
