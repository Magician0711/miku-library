# 常见问题

[← 返回 README](../README.md)

### 下载一直停在 0%

先看任务状态：「正在发现下载节点」表示还没找到其他用户，「已连接 N 个节点 · 等待可用分片」表示有连接但对方暂时没有可用的数据。旧资源可能已经没人做种，换一个字幕组或更新的资源通常就能解决。

- 内置下载器会让系统为每个连接选择网络路由，同时使用 IPv4 / IPv6，不需要修改 Windows 或代理设置。
- 种子没有 Tracker 时，会补充少量公共 Tracker（可在「偏好设置 → 网络」关闭）；私有种子不受影响。
- 90 秒收不到数据会自动换用其他来源，可在「传输与队列」调整或关闭。
- 点「恢复」会重新寻找节点。

### 下载的视频打不开或没有字幕

本软件不含播放器，视频交给系统默认播放器打开。番剧多为 HEVC / 10bit 编码并带 ASS 特效字幕，Windows 自带播放器通常无法正常显示。请安装 PotPlayer、mpv 或 MPC-HC，并设为 `.mkv` / `.mp4` 的默认打开方式。

### 启动时提示下载目录不存在

保存的下载目录被删除、改名或所在磁盘未连接时会出现。选择新目录即可；已有的文件不会被移动。

### 追更提醒没有出现

它只在启动时检查一次，并且只针对你下载过的番剧和字幕组。以下情况不会提醒：

- 该字幕组还没有发布新集，或资源站暂时没有返回结果；
- 已经下载到最后一集；
- 新集被「忽略」过。

### 海报不显示或占用空间较大

海报缓存在「偏好设置 → 存储」中可以查看大小并清理，清理后会在下次显示时重新下载。

### 想再看一次欢迎页

退出软件，把 `%USERPROFILE%\.anime-nexus\config.json` 中的 `disclaimer_accepted` 改为 `0`，再次启动即可。

### 打开第二个窗口没有反应

同一数据目录只允许运行一个实例。再次打开会切换到已经运行的窗口；如果它还在启动中，请稍等再试。
