# Miku Library 1.0.0 更新说明

相比上一个发布版本 0.7.0 的主要变化。每一步的技术细节和验证记录见 [UI_REWRITE.md](../UI_REWRITE.md)。

## 升级前请先看

- **项目改名**：Anime Nexus 现在叫 Miku Library，程序文件是 `MikuLibrary.exe`，并换了新 Logo。
- **旧数据不会自动迁移**：数据目录改为 `~/.miku-library`，第一次打开会重新显示欢迎页。追番列表、下载记录和设置需要重新建立。
- **旧版导出的备份不能导入**：备份格式的标识随改名变了。
- **默认下载位置**改为系统「下载」文件夹下的 `library`。已经下载到其他位置的视频不会被移动或删除，可以在设置里把下载目录指回去。

## 内置播放器

- 视频直接在程序里播放，基于 libmpv。找不到 libmpv 时退回系统默认播放器。
- 侧栏新增「正在播放」，离开页面后声音继续，随时可以回到画面。
- 支持悬浮控制条、键盘操作（空格、方向键、`F`、`M`、`Esc`）、单击暂停、双击全屏；记住每个视频的播放位置、音量和超分档位。
- Anime4K 实时超分：关闭、流畅、高画质三档。

## 全新界面

- 全部页面改用 Qt Quick 重写，并按 Apple 设计语言重新设计：玻璃侧栏、胶囊形控件、统一的字号层级。
- 宽窗口下海报和表格铺满内容区，详情页分两栏；窄窗口下侧栏收成图标栏，`Ctrl+\` 可以手动切换。
- 侧栏展开和收起时内容逐帧跟随，鼠标悬停展开时会推开内容，不再遮挡。
- 深浅色切换改为连续淡入淡出，快速连点也不闪烁。
- 设置重新分为通用、下载、资源与网络、数据、关于五组。
- 窗口按钮改为圆形，与窗口圆角同心。

## 追番与下载

- 程序常驻系统托盘，关闭窗口时可以选择最小化到托盘或退出，选择可以记住。
- 定时检查追更（启动时，或每 3、6、12 小时），每部番可以设为不追更、提醒或自动下载。
- 下载完成和发现新集时发送系统通知。
- 详情页新增「季度与篇目」，可以切换同名番剧的其他季度、剧场版和篇目，整页内容随之切换。
- 一键下载先弹出选项窗口，可选字幕语言、清晰度和集数范围。
- 下载前检查磁盘空间，放不下时直接说明原因。
- 默认下载完成后继续做种，要关闭时会说明影响。删除任务时一并清理种子文件和空文件夹。

## 网络与数据

- 支持跟随系统代理、不使用代理、HTTP 和 SOCKS5 代理。
- 连不上 Bangumi 时显示上次保存的放送表，并注明更新时间。
- 可以导出和导入备份，包含设置、站点、追番列表和下载偏好。
- 再次打开程序时不会启动第二个，而是把现有窗口带到最前，并检查一次软件更新和番剧新集。

## 无障碍

- 主要操作都能用键盘完成，焦点环对比度提高到 6:1。
- 站点状态用形状区分，不只靠颜色。
- 跟随 Windows 的文本大小（最大 150%）和对比度主题，屏幕阅读器能读出控件名称。

## 主要修复

- 全新环境点「同意并开始使用」后程序直接退出。
- 拉伸窗口时封面反复重新加载。
- 详情页悬停侧栏时「可用资源」等文字闪动一帧。
- BT 监听端口被占用时无法自动换用其他端口。
- 放送表偶发「Connection closed」加载失败。

## 验证

- 9 组自动测试共 530 项全部通过。
- 用全新的数据目录走完欢迎页，程序能正常进入主界面，默认下载目录为 `library`。
- 内置播放器用自制的 1080p 测试视频验证。真实下载流程、托盘右键菜单和随系统切换主题没有在本版手动验证。

## 从源码构建

`libmpv-2.dll` 超过 GitHub 的单文件大小上限，没有放进仓库，获取方法见[开发文档](development.md)。
