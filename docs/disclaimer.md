# 使用声明

[← 返回 README](../README.md)

首次启动时需要阅读并同意以下声明，之后可在「偏好设置 → 关于」随时查看。

1. 本软件仅是番剧资源的检索与下载管理工具，不提供、不存储、不上传任何影视内容。检索结果全部来自第三方公开站点，其内容与本软件无关。
2. **通过本软件下载的番剧仅供个人学习与交流使用，请在下载后 24 小时内删除。**
3. 请支持正版。喜欢的作品请通过正版平台观看或购买，以支持创作者。
4. 请遵守所在地法律法规。不得将下载内容用于商业用途、公开放映、上传分享、二次分发或其他侵犯著作权的行为；由此产生的一切法律责任由使用者自行承担。
5. BitTorrent 下载时会同时向其他用户上传已下载的数据（做种），下载完成后默认继续上传。请了解所在地关于 P2P 传输的规定；可在「偏好设置 → 传输与队列」限制上传，或开启下载完成后自动停止。
6. 如权利人认为某些资源侵犯其合法权益，请联系提供该资源的站点处理。本软件不对第三方站点的内容、可用性及合法性负责。
7. 本软件按「现状」提供，不对下载内容的完整性、安全性及因使用本软件造成的任何损失承担责任。
8. 继续使用即表示您已阅读、理解并同意以上全部声明。
