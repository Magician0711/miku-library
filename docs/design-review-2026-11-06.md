# Windows 页面设计审核 · 2026-11-06

## 范围与方向

使用用户指定的 [apple-design-skill](https://github.com/dickwu/apple-design-skill)，版本
`ff4ebddf0488598723a82bfdce1afb04de0b1c44`。安装在用户 Codex skills 目录；只将设计原则应用到 Windows Qt Widgets，不引入 Apple 平台资源或组件。

Miku Library 面向希望按番剧、字幕组发现和管理视频的桌面用户。页面的视觉重点是海报与可用资源；导航、状态和设置退居其次。保留 #39c5bb、Windows 右侧窗口按钮、无边框缩放、Ctrl+K、输入法处理和原有后端。

设计判断：这个产品已拥有丰富的海报内容，额外的大幅宣传横幅、渐变和多层玻璃会分散注意力。采用中性色画布、紧凑海报网格、局部青绿色选中态。移除详情介绍的外层卡片边框和下载统计的三个独立外框；搜索页的快捷键说明移到标题下方的说明行。

## 规范依据与整改

- **High / 层级** — 原标题、统计说明和操作共用一行，在密集页面容易相互挤压。
  `layout.md › Visual hierarchy`: “Order content by relative importance.”
  将标题与说明分行，操作置右，窄宽度自动改为上下布局。实现：`src/ui/Widgets.cpp` 的 `PageHeading` / `pageHeader`。
- **Critical / 文字对比** — 原浅色辅助文字 #7d8e8c 对 #f8fafa 为 3.28:1，小字号说明不够清楚。
  `accessibility.md › Vision`: “Strive to meet color contrast minimum standards.”
  辅助文字改为 #636d7a，对 #f7f8fa 为 4.94:1。重要文字仍使用更深的文本色。实现：`src/ui/Theme.cpp`。
- **Medium / 内容组织** — 下载任务用统一统计区，追番筛选移出标题行，设置分区改为垂直导航。
  `layout.md › Visual hierarchy`: “Group related items to clearly express related information or functions.”
  设置的应用/放弃逻辑和分区切换后的状态保留。
- **Medium / 集合** — 保留海报网格，不增加轮播或装饰性主视觉。
  `collections.md › Best practices`: “Use the standard row or grid layout whenever possible.”
  星期栏继续居中，内容间距 12 px，卡片横向间距 16 px；标题和元数据紧随海报。
- **Medium / 动画** — 保留可中断的短过渡，修复 ToggleSwitch 忽略系统减少动画设置的问题。
  `motion.md › Best practices`: “Let people cancel motion.”
  不增加实时背景模糊，所有基础内容表面使用不透明色。

## 页面结构

常规窗口（1320 逻辑像素）:

```text
应用标识 / 当前页面                          主题  最小化 最大化 关闭
侧栏 200 │ 页面标题                                    操作
         │ 页面说明 / 计数
         │                 居中的星期选择
         │ 海报     海报     海报     海报     海报
         │ 标题     标题     标题     标题     标题
```

紧凑窗口（1080 逻辑像素；页面头单独检查至 440 像素）:

```text
侧栏     │ 页面标题
         │ 页面说明
         │ 操作（空间不足时换行）
         │ 居中的星期选择
         │ 海报     海报     海报     海报
```

详情页采用开放式海报与介绍，资源过滤器按可用宽度换行；字幕组折叠、更新、去重和播放语义不变。设置页使用 116 px 分区导航与可滚动表单，两列设置保留解释文字与控件的对应关系。

## 平台取舍

- Skill 中禁止应用单独切换外观、macOS 菜单栏与独立设置窗口等要求不直接适用于本次 Windows 产品。遵循用户既有要求，保留“跟随系统 / 浅色 / 深色”和应用内设置。
- 保留现有自绘线性图标；不分发 SF 字体或 SF Symbols。
- 不进行 QML 迁移，不改 HDR 识别、下载引擎、搜索来源、配置结构和用户记录。
- 本次没有处理主题切换延迟。该问题已在后续改动中解决，见下方「后续修正」。

## 验证方式与边界

`DesignReviewSmoke` 使用真实 MainWindow 和生产页面，在临时用户目录中验证浅色/深色、1320/1080 逻辑像素、六个主要页面和设置所有分区。内置引擎不启动，对外网络使用本机不可用代理阻断。可选读取本地公开放送表缓存和海报，作为视觉审核样本；不会写回个人记录，也不会把缓存打进产品。

截图在 `build/design-review/`；只有通过人工查看的截图才用于最终交付。另运行中文输入、控件、详情/追番、设置及浮层现有测试。Windows DPI 缩放与自定义更大文本是不同事项；没有验证的系统文字放大、屏幕阅读器和高对比度主题，不作通过承诺。

## 后续修正

审核后的代码复查调整了以下内容，上文的验证结果仍是当时的记录：

- 恢复设置分区的滑动选中背景（本次改版时被去掉），样式与侧栏一致。
- 焦点框只在键盘操作时出现：鼠标点击导航和设置分区不再留下描边，启动时也不显示。
- 去掉没有信息量的说明文字。搜索页改为显示 `Ctrl + K`，下载页没有任务时显示「暂无任务」，设置页显示引擎状态。
- 把遗留的绿色调灰色换成中性灰，删除失效的样式规则。页头的操作按钮文字变长时也会重新判断是否换行。
- 主题切换耗时从约 260 ms 降到约 12 ms，方法见[更新记录](../UI_REWRITE.md)。
