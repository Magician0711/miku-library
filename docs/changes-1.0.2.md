# Miku Library 1.0.2 更新说明

相比 1.0.0 的主要变化。每一步的技术细节和验证记录见 [UI_REWRITE.md](../UI_REWRITE.md)。

## 升级前请先看

- **侧栏换成了底部导航栏**：导航悬浮在窗口底部，平时只显示图标，鼠标移上去展开名称。`Ctrl+\` 收起侧栏的快捷键随侧栏一起删除；`Ctrl+K` 搜索照旧。
- 数据目录、配置和下载记录与 1.0.0 相同，直接覆盖解压即可继续使用。

## 界面

- **透出桌面的背景**：Windows 11 上窗口背景是系统的模糊材质，后面的窗口和桌面透出来；切到别的窗口后模糊仍然保留。Windows 的「透明效果」关闭、开启对比度主题或在 Windows 10 上时保持不透明。
- **底部导航栏**：窗口底部居中悬浮的模糊玻璃条，页面内容可以滚到它下面。鼠标移上去时以中间一项「我的追番」为中心展开名称；点左侧 Logo 回到「本季放送」。
- 设置、站点、下载等页的卡片改为半透明，不再是一块块白色；浅色下的次要文字相应加深，保持清晰。
- 详情页左侧的封面和简介固定不动，展开长简介后才可以向下滚动；窗口较矮时封面自动缩小，按钮不会被导航栏挡住。

## 播放器

- **补帧**：控制条新增「补帧」，按 `I` 切换。「平滑」按屏幕刷新率混合相邻帧；还可选「运动补偿」：Windows 版自带 VapourSynth R82、MVTools v29 和嵌入式 Python 3.13，开箱即用（压缩包因此增大约 18 MB）。

## 多语言

- 新增繁體中文、English、日本語，默认跟随 Windows 显示语言，首次启动向导和「偏好设置 → 通用」都可以切换。

## 下载任务

- 可按「全部 / 未完成 / 已完成 / 出错」筛选；新增所有未完成任务的「剩余」大小和预计时间。
- 没有选中任务时，按钮作用于全部任务；出错的任务可以「重试」。
- 已下载完的集数可以直接双击播放；合集可以「按顺序下载」。

## 修正

- 点导航栏按钮时，点击会穿透到下面的海报，打开别的番剧详情。
- 透明背景里有时出现 Windows 7 样式的旧边框和标题。
- 窗口右上角在自绘按钮旁隐约多出一组系统按钮。
- 首页封面光两侧和顶部有一条空缺。
- 从 `dist` 启动时内置播放器不可用（打包没有带上 libmpv 和 Anime4K 着色器）。

## 其他平台

- 代码已移植到 macOS 和 Linux（Linux 在 Ubuntu 22.04 上构建并通过全部测试）。本次只发布 Windows x64 便携版；macOS 版从未在真机上编译过。
