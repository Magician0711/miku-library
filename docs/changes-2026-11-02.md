# 2026-11-02 优化与归档

本次不修改 HDR、杜比视界等媒体格式标签识别；TitleParser.cpp 与修改前备份的 SHA-256 完全一致。

## 已完成

- 站点开关与导入内容持久化到用户目录；有效自定义 RSS 自动参与搜索，全部启用来源按并发队列执行，详情页来源列表随每次检索更新。
- 明确区分搜索源与网页目录，拒绝未知 JSON 适配器和重复站点 ID，避免标记启用却没有执行搜索。
- Anime Garden 支持分页，RSS 跟随同站 next 链接；失败、循环或到达保护上限报告部分结果，不静默冒充完整结果。
- 取消搜索立即释放网络任务，替换检索不再混入旧结果；已完成任务不继续积累。站点连接测试保留异步适配器直到结束。
- 短英文别名使用词边界，减少作品误匹配，保留中日文匹配及英文分隔符变体。
- 追番详情右上角改为「查找可下载资源」，跳至同一作品的搜索详情并重置页面状态，恢复可下载资源展示。
- 内置下载器无数据停滞时尝试其他来源，默认 90 秒、可调整或关闭。先停止原任务，再添加替代来源；接收数据后不切换，避免重复文件。已尝试来源写入库存。
- qBittorrent、Transmission、aria2 新增可选本机接口控制，支持进度、暂停、恢复、保留文件的移除、完成后停止和本地库存同步。支持本地种子的缺集选择。
- 数据目录单实例锁和本机参数转交，降低多个窗口同时写本地库存的风险。
- 命令行导入走统一番剧下载流程，使用所选下载器、番剧目录和去重策略；不明确的作品先选择所属番剧。

## 验证与边界

使用自生成种子和本机 HTTP / Tracker / RPC 模拟服务验证，无需下载真实影片。新增覆盖：全站点调度、分页与循环保护、取消、配置持久化、单实例 Unicode 参数转交、停滞换源、三个下载器接口、追番跳转和连接配置 UI。外部接口测试不等于已在每种真实下载器版本上完成端到端认证。

默认目录 90 个条目中有 8 个内置可搜索来源；字幕组网页、私有站和历史站不会凭网址自动获得适配能力。其他站点可提供有效 rss_url 接入。没有分页功能的站点依然只能提供其接口返回的资源，无法保证包含全部历史话数。

BitComet 与自定义下载器保持程序启动方式。外部本机控制需自行开启对应 Web UI / RPC；完成自动停止需要本应用运行。仅有磁力、尚未取得文件元数据的缺集合集仍建议内置下载器处理。新任务限速传给外部客户端，客户端的全局限制仍生效。

实际下载速度取决于可用节点和网络；已收到数据的任务保留原来源。HDR 标签继续沿用原有识别逻辑。
